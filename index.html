Chamber One

TaskFlow

Full-stack SaaS application

A multi-user project and task manager. Login issues a signed JWT, and every query is scoped server-side to its owner — one account cannot read or modify another's data even by typing an ID straight into the URL. Passwords are hashed with PBKDF2; nothing is stored in plain text.

Data model
Users own projects; projects own tasks, each carrying status, priority, and an optional due date.
Notable
Written against raw SQL rather than an ORM, so every query is visible and reviewable in the source.
Frontend
No framework, no build step — structured so each UI section maps cleanly onto a future React component.
  • Flask
  • SQLite
  • PyJWT
  • PBKDF2
  • Vanilla JS

Chamber Two

Snip

URL shortener & click analytics

Turns a long URL into a six-character code, or a custom alias, and redirects on a single lookup. Codes come from a cryptographically strong source rather than an ordinary random function — predictable codes would let anyone walk the sequence and read other people's links.

Data model
Links keep a running counter for instant reads; a separate clicks table stores one timestamped row per visit for real history.
Charting
Click trends render as hand-drawn inline SVG sparklines, with no charting dependency.
Guardrails
URLs validated as absolute http(s); custom aliases checked against a reserved list so they can't shadow real routes.
  • Flask
  • SQLite
  • secrets
  • Inline SVG

Chamber Three

Repo Pulse

GitHub analytics dashboard

Point it at any public repository and it pulls live data from the GitHub API — language breakdown, weekly commit activity, contributor rankings, open and closed issues and pull requests. Up to five repositories can be compared side by side with shared legends and a summary table.

Hard part
GitHub computes some statistics asynchronously and answers 202 while it works. The client polls with backoff and degrades gracefully instead of surfacing an error.
Rate limits
A five-minute per-repo cache keeps demos inside the 60/hour anonymous ceiling; adding a token raises it to 5,000.
Testing
Twelve unit tests run against recorded fixtures, so the suite needs no network access.
  • Flask
  • GitHub REST API
  • Plotly.js
  • pytest

Burial chamber

Ledger

AI personal finance agent

Built on a single rule: the model decides what to do, deterministic Python does the math. Ask whether you can afford a $2,500 trip in December without touching your emergency fund, and it chains real tools across your transaction history — then shows every tool it called, in order, with timings. It will never invent a figure it hasn't actually calculated.

Agent loop
Eight tools covering transaction lookup, balances, spending breakdowns, recurring-payment detection, period comparison, cash-flow forecasting, semantic search, and budget scenarios. Hand-written in roughly 120 lines rather than pulled from a framework.
Receipts
A vision model extracts line items from a photo; Python reconciles them against the total, matches the receipt to the right card transaction, and splits one charge across the categories it truly belongs to — apportioning sales tax proportionally.
Scenarios
"What if I buy a $35k car with $5k down?" becomes structured parameters, real amortization, and a check against actual cash flow. It correctly refuses scenarios you can't afford.
Verification
144 backend tests. Amortization checked against a known textbook value. A fake Anthropic API exercises the exact wire format, including tool calls, retries, and vision payloads.
